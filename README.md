# Jewish Benefactors History

אתר מחקרי בעברית על יהודים היסטוריים, לפני המאה ה־20, שפעלו בצורה חיובית למען חיי היהודים בארץ ישראל ובעולם.

## מטרת האתר

האתר נועד להציג דמויות יהודיות שפעלו בתחומי הנהגה, חינוך, דיפלומטיה, צדקה, התיישבות, זכויות אזרח ושימור החיים היהודיים.

## מבנה האתר

- `index.html` — דף הבית
- `about.html` — אודות האתר
- `timeline.html` — ציר זמן היסטורי
- `gallery.html` — גלריית דמויות
- `sources.html` — מקורות וקריאה נוספת
- `people/` — דפים אישיים לכל דמות
- `assets/css/style.css` — עיצוב האתר
- `assets/js/main.js` — נתונים, ניווט, גלריה וחלון צף לתמונות
